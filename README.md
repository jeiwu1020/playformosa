# 島遊無界 · PLAYFORMOSA

A standalone, local-first static mini-game studio homepage. One playable game: **四肢各有想法 / 跳遠**, the first available event in the 十項全能 challenge. This project is separate from any previous arcade platform.

## Run checks / build

Requires Node.js 20+. No install or runtime framework required.

```sh
npm test
npm run build
node scripts/verify.mjs
# or all together:
npm run check
```

Deployable static directory: `dist/`. `public/index.html` is also regenerated by the build for direct static serving; source content lives in `src/render.mjs` and `src/catalog.mjs`. Serve from a site root, not a path prefix. Root-relative homepage URLs require HTTP hosting rather than opening an HTML file with `file://`.

## Extend the game catalog

1. Put a real, self-contained game build in `public/games/<slug>/`, preserving relative asset imports and dependency licenses.
2. Add an `available` entry with a `/games/<slug>/` path in `src/catalog.mjs` only when it is actually playable.
3. Rebuild and verify. Planned entries never produce play links. The roadmap is native `<details>` and is collapsed by default; the homepage works without JavaScript.
4. Ten-event series membership currently follows `event` labels in `catalog.events`. For a later non-decathlon collection, add a separate section rather than misrepresenting its availability as part of the ten-event count.

## Included game / assets

`public/games/long-jump/` contains **v9 Taiwan/world/space adventure** over the released v8 four-limb mechanics. Taiwan's22 counties/cities lead to overseas landmarks, a world-route achievement and atmosphere/Moon/Mars/Saturn; flight remains uncapped. Cumulative approximate adventure kilometres are distinct from raw physics and not distance from Taipei. See `docs/long-jump.md` for the conversion and reference-scale caveats. No new food commentary is added in this batch. The comparison experiment, other platform files, original hero image and Three.js license are preserved.

The user approved the proposed progression from realistic clouds and atmosphere to orbital scenery, Moon/deep space and restrained Taiwanese fantasy surprises. Work targets only `preview/hurdles`, based on verified `f0ff36a3c0afe1bdf3bfa5b34086a4626e810a1d`, not the older standalone Site.

Keep the original low-poly mint/cream/orange palette, athlete, controls, physics, scoring, height comparisons, ending and sharing. Retain the branch's later landmark framing and platform integration. Add layered cloud banks, a high-atmosphere horizon, orbital station/probe silhouettes, a progressing Moon and comet, then a bubble-tea planet, pineapple capsule and tiny floating night-market stall. Real references and imagined scenery remain explicitly distinct.

Use actual height and the existing logarithmic travel projection for appearance and progress. Existing simulation time alone drives cosmetic animation. Freeze scenery with the result state; replay, capture and pause must be deterministic. No external assets, services, persistent state or new controls. Keep the centre around the athlete clear. Reuse a fixed geometry pool and reduce secondary detail on narrow screens.

Alternatives considered: more uniform stars is cheap but does not create progress; many independent randomized props clutter mobile and complicate replay. Chosen: bounded height-driven foreground/middle/distant layers, one dominant new landmark and occasional supporting detail.

Validation covers actual scene geometry at desktop/mobile sizes, altitude boundaries and extremes, render state immutability, capture restoration, bounded meshes, existing pole-vault tests and aggregate project checks. Cloud software-renderer evidence is not a physical-phone/GPU performance claim.

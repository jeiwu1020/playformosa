# 接棒啦！視窗修正候選版

日期：2026-11-03。基底：preview/hurdles 的 1862880407edecb4270d1778641cf6770ba4b548。
本文件不是發布紀錄；未更新遠端分支、未部署、未變更 main。

## 調整

- 桌面版：平台共用介面把原型的浮動底列改為一般排列，但原型仍留下零內距。補回底列左右及底部內距，讓文字不貼住裁切用的圓角。
- 手機 Web App：載入平台跳遠已有的 visualViewport 量測與根捲動復原。接棒原本只會重算 canvas 尺寸，未處理轉向後延遲出現的根座標位移。
- 工具列與畫布放在同一個固定、依可視區域大小配置的外框，避免外框再形成獨立捲動容器。
- 保留原本轉向暫停、釋放觸控與重新量測畫布的流程。不用人為加減觸控座標的補丁。

只改接棒 index.html，新增接棒 viewport.css；沒有改動物理、相機、輸入換算、得分、分享圖片、角色模型或任何共用遊戲程式。額外變更均為測試及來源驗證紀錄。

## 驗證與限制

- 回歸涵蓋三次直向→橫向→直向、延遲根位移、回前景復原，以及一般瀏覽器、縮放、鍵盤與複製文字欄不被強制回捲。
- 既有遊戲控制器測試涵蓋暫停、繼續、重新開始、結果分享、釋放觸控、零尺寸與延遲尺寸變化。
- 新增修訂紀錄會先驗證目前完整 HTML 雜湊，再精確移除新增的兩個載入項，復原到原始 HTML 雜湊及 Git blob。舊來源紀錄保留不動；額外 HTML、圖示變更、遺漏或重複載入項皆會被拒絕。
- 自動化使用真實來源與 JSDOM／Three.js 數學，不能代替瀏覽器排版或 iOS 系統的觸控命中測試。此環境啟動 Chromium 時受到 socket 權限限制，一次權限重試仍失敗，因此沒有宣稱完成瀏覽器或 iPhone 真機驗收。
- 完整檢查及發布頻道預檢結果保存在 evidence/viewport/full-check-final.log。

## 真機驗收

1. 在 iPhone 主畫面 Web App 開啟接棒，開始遊戲。
2. 橫向再轉回直向，重複三次。應暫停，工具列應完整可見。
3. 直接點按看得到的「繼續」、音效、重來及說明，確認不必刻意點上方。
4. 繼續後拖曳手掌，確認觸控與畫面位置一致。
5. 遊戲結束後重做旋轉，驗證成績、分享及複製文字視窗；複製欄出現鍵盤時不可被強制捲回。
6. 桌面常用尺寸與縮放下確認左下操作提示及十根進度完整可見。

## 尚未完成的真實裝置驗收

自動測試使用真實物理、Three.js 場景與 2D 畫布；WebGL 裝置邊界在控制器測試中以替身代替。CSS 測試不具備實際瀏覽器的排版及命中測試能力。

本機 Chromium 被執行環境阻擋；可用的雲端瀏覽器無法連入此隔離副本，且上一輪顯示其 WebGL 不可用。因此尚未宣稱新結算版面或 iPhone Web App 的實際畫面／觸控驗收通過。

獲得指定分支發布同意後，應先核對最新遠端頭、只帶入本候選差異，再測試：
1. 最後一棒接住、掉地板與跌倒三種結束，照片都看得到棒子。
2. 結算開啟時連續直橫直切換，照片不換張、不裁邊，細節與分享／排行榜可操作。
3. 開關細節、開關排行榜、取消系統分享與回到結算，成績和照片保持一致。
4. 再來一局後舊圖不殘留，新圖與新成績一致。
5. 下載／分享圖片的照片與結算相同。

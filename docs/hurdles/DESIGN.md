# 四肢各有想法－跨欄
Approved delegated brief: a private standalone 110m hurdles game for PlayFormosa. Original four-limb runner and J/K arms, A/S legs retained verbatim from latest main. No changes to existing sites or repositories.

Arcade time trial, ten toppleable hurdles. Alternating short leg taps build speed; holding then releasing a leg jumps. Arms balance and recover stumbling; airborne leg controls physically change hurdle clearance. Finish time alone ranks, humorous performance-based distinctions are separate. Stumbles recover, not game over. Pause clears held inputs and charge. Rotation pauses without intercepting resume. Responsive arena and four large buttons dominate. PNG finish card, local best, mobile file share with honest download fallback, explicit Threads image-attachment limitation. Audio reuses verified selected long-jump assets and credits.

Exact model identity is preserved. Preferred renderer is Three.js; a software triangle renderer may render the same scene and same mesh, never a substituted flat mannequin. No new raster art is needed: all course art is procedural geometry in established palette.
